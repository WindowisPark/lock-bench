Key Insights

  • Redisson Pub-Sub이 모든 조건에서 100% 성공률 - Lettuce spinlock의 LOCK_TIMEOUT 문제를 완전히 해결
  • Trade-off: Redisson c=50에서 p95 2.7초 - pub-sub 대기열이 길어지면서 latency 상승. 성공률 vs 지연시간 트레이드오프
  • PASS 기준 (99%+ & p95<500ms): Redisson PLATFORM c=10,20 PASS / VIRTUAL c=10만 PASS
  • Lettuce의 구조적 한계: spinlock + fixed retry(10)이므로 경쟁이 심해지면 LOCK_TIMEOUT 선형 증가
  • Redisson 권장 범위: PLATFORM c≤20, VIRTUAL c≤10에서 품질 기준 충족
